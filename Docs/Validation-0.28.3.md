# 0.28.3 验证记录

用 5 本生成的 PDF／UVZ 测试宽窄窗口、展开及收起书单、长文件名、PDF 与 UVZ 切换以及图书读取失败。旧版 50 次检查中有 26 次书名栏不可见，部分表单高度降至零。新版 50 次均可见。另用 4 本实际图书的临时副本重复 40 次切换检查，书名栏均可见。

原生测试检查窄窗口展开书单时 PDF 与 UVZ 均保留图书信息，分析失败时右侧显示原因并禁用编辑。图书已经分析时可照常修改字段、勾选并保存。

通过 448 项功能检查、102 项原生界面检查和 13 项 Quick Look 控制器检查。框选 OCR 和批量 PDF 识别的测试使用独立的默认识别偏好。既有简体 OCR 样例将“丛书名”识别为“从书名”，未计入通过数。

适用于 Apple 芯片 Mac、macOS 14 或更新版本。发行包采用临时签名，未经 Apple 公证。
