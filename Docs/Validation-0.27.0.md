# 0.27.0 验证记录

## 1. 阅读目录

生成的 PDG 样本覆盖八种页面类型。在无电子目录时，每种实际存在的类型只有一个入口。保存书内目录后，以页面所指类型替代对应的默认入口，测试覆盖前言多页、无跳转父组下的前言子项、正文、目录、附录及封底。未定位的旧书签按原类型显示，仍可继续为其他页面类型补入口。也验证按作者原有顺序呈现已完整编排的目录和清空目录后恢复基础入口。

原生阅读窗口验证了侧栏去重、点按「封底」跳到实际页面、前言起始处不会误选封面。书内目录未列出的正文页面可使用现有页码导航。本轮只用生成样本写入和回读。

## 2. 回归与发行

通过 424 项功能检查、79 项原生界面检查和 11 项 Quick Look 预览控制器检查。OCR 套件的一项简体夹具仍将「丛书名」误识别为「从书名」，与旧版一致。在线查询使用模拟返回数据。

发行包支持 Apple 芯片 Mac、macOS 14 或更新版本。采用临时签名，未经 Apple 公证。
