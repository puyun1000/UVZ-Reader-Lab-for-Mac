# 图书信息提取与核对

本功能使用本机 Vision OCR 和可审查的字段规则，不调用远程模型，也不宣称覆盖全部 CIP 编目规则或可自动鉴定书目。

## 参考资料

- GB/T 12451-2001《图书在版编目数据》，第4—7节的项目、标识符与四段印刷结构。官方状态：[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=D3F64879364A05E989F28C2344DCCB24)。该版已被2023版替代；旧书仍大量使用旧结构。
- GB/T 12451-2023《图书在版编目数据》，第5节、7节、8节及附录A。[官方元数据](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=4AF9725FBE25C9A878BAC0D0CA8E119D)，[贵州大学出版社发布的全文](https://press.gzu.edu.cn/2024/0726/c1533a226768/page.htm)。本次核对了全文扫描件及附录中的书名、责任说明、版本、出版项、丛书、合订书等结构。

2001版出版社PDF原链接当前返回访问错误；本次能核对网页缓存中的结构条目及出版机构的说明，未对其完整扫描件逐页复核。2023版正文虽列载体形态等描述项，第8节规定的印刷内容不要求逐一印出所有描述项；程序不会据此推算缺失页数。

## 提取过程

先准确识别整页。在能同时定位CIP标题与核字号行时，对同一区域裁切并放大，再读一次小字；不改变原图。局部结果必须保留区域标题与原先有效的ISBN，否则退回整页结果。两次识别是同一份证据，不会冒充两个独立来源。

由CIP标题进入描述区，识别ISBN、检索条目和旧／新核字号边界。描述区按责任说明斜线、版本区域、出版地冒号、出版者及出版年月逗号、丛书括号处理。跨行汉字与书号作有限拼接，副标题、并列书名和责任说明保留。出版社不限于“出版社”后缀，可包含书局等出版机构及合作出版项。

CIP之外只接受明确字段标签、独立出版机构名称、版次年月和有依据的页数。印刷年月、CIP核字号年份、定价、字数、责任编辑与设计人员不用于补齐普通书目字段。ISBN必须完整通过10位或13位校验，不猜校验码。

封面、书名页作额外读取；已知书名、作者等只有与独立识别文字一致才用于核对。无标签的大字版面推测明确标记为推测。无法识别或空白页面会提示，不把缺失的结果视为一致。

0.12单书与批量使用统一的MetadataResolver：比较BookInfo／文档信息、CIP、出版信息、书名页、封面及文件名的候选。明确著录的权重高于版面推测，两个不同明确来源相互印证时可替换原有值。相同来源与物理页的重复结果不叠加票数。只有单一明确来源与合法原值冲突时，通常保留原值并提示核对；没有原值或原值格式无效时，可采用明确著录。

相同作者的常见责任后缀在繁简归一化前比较，避免“著”转写影响一致性。同年且明确的月份可补齐年份；ISBN校验与普通字段格式在选择前检查。CIP、出版信息、封面、书名页、文件名各自保留来源和物理页，选择推荐值不删除不同证据。手工编辑与手工采用的值可保护，单书保存前可撤回最近的自动调整。分值用于规则排序，不是概率或准确率。

## 写入边界

分析不改文件，建议默认不勾选。冲突、推测或缺项需要逐本确认。应用前对所有勾选项目检查目标冲突，并对每本书检查原文件与旁存内容指纹。停止在当前图书处理完后生效；已经完成的改名保留，不提供整批原子撤销。默认只改名；勾选保存信息后才写入DAT／旁存。

## 尚有限制

书法竖排、异形字、破损扫描、缺失标点、印刷错误、合订多作者、多个丛书、多个ISBN、缺少核字号边界仍可能无法准确分解。BookInfo本身也可能把丛书、总主编混入书名作者；本版可根据多个明确来源推荐更合理的值，所有结果仍以草稿形式供用户核对后保存。尚未进行大规模人工标注的准确率评估，不输出虚构的准确率。

测试采用自造文本覆盖结构与噪声，另在用户授权书籍的副本上验证OCR和应用流程；不分发标准扫描件或测试图书。


## 0.13.0 的识别与保存实现

单本、批量与框选识别共用 TextRecognition。语言列表先按本机 Vision 支持的标识过滤；提供自动、简体、繁体、日文、英文优先项，自动语言不强制简繁转换。竖排通过列投影、字块重排后识别，保留图像坐标。已有横排跨列证据时不盲目当作竖排；Vision已正确识别的旋转拉丁文字直接保留，不再字块重排。复杂混排、书法与模糊图像可能无法准确分段。

TitleNormalization在共享字段推荐后运行，保护手工锁定字段。仅明确括注或分隔的丛书前缀移入空缺丛书项；不按书名中任意出现的“文库”等字样强拆。短词并列、合订关系或多个空格边界保留核对提示。原始来源值保持可见。

PDF使用原生文档属性，标准字段同步写入Title、Author、Subject等键；扩展字段使用文档内部UVZReaderLabMetadata字符串保留。DjVu使用文档级共享注释中的metadata键，标准字段和完整字段同时保存，保留原注释、文字层及目录。均先在临时文件写入、回读全部字段与页数，通过源文件快照检查后才提交名称及内容；失败不先改名。加密PDF当前拒绝元数据改写，避免改变加密状态。

历史信息旁置目录只有BookInfo时迁入后清理；包含目录编辑或用户文件时仅删除已嵌入的BookInfo，保留其余内容。元数据存储不等于目录编辑存储。

实现参考：[Apple Vision文字识别](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)、[PDFKit文档属性](https://developer.apple.com/documentation/pdfkit/pdfdocument/documentattributes)、[DjVuLibre djvused手册](https://djvu.sourceforge.net/doc/man/djvused.html)。

验证见Tests/test_native_information.py、test_metadata_rules.py、test_multilingual_ocr.py，以及发布Verification.json。合成样张测试不能代表所有扫描图书的识别准确率；实际图书只作本机抽查，不随源码分发。
