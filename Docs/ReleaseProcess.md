# 发布与同步流程

自0.15.0起，每次交付新版都同步到既有仓库：
https://github.com/puyun1000/UVZ-Reader-Lab-for-Mac 。保留仓库既有提交及版本，不覆盖标签、不更改可见性。

1. 更新应用及两个Quick Look扩展的版本、功能说明和更新说明，保持打包内容与仓库一致。
2. 原生构建并验证本轮功能、交互、预览，核验Mach-O最低系统版本；检查来源图书未被意外改写。
3. 从干净应用包生成DMG及源码包，核验签名、镜像与复制后的文件哈希，生成SHA-256和去除私人路径的验证摘要。
4. 将本目录的源码、资源、文档、第三方源码和许可证同步到既有Git检出，保留远端新增内容；排除生成应用、缓存、测试图书和私人预览图。
5. 扫描拟提交源代码与分发文件中的凭据，确认没有用户图书或临时测试产物。
6. 推送源码提交，以同一提交建立版本标签；调用scripts/publish-release.py发布DMG、源码包、校验表和验证摘要。
7. 下载或检查GitHub附件的SHA-256，核对标签、提交、版本及安装包一致后交付。

发布脚本要求已有Git检出、干净提交、标签指向当前提交及已推送的主分支，不读取或打印认证令牌；通过GitHub CLI的现有登录发布。首次运行时若未找到gh，可用GH_BIN指定本机安装位置。

Source代码包保留本项目源代码及第三方源码／许可。分发包不包含用户图书；截图中如包含阅读样张或私人路径，不上传到仓库。
