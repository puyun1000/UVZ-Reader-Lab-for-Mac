# 0.22.0 验证记录

## 1. 文本 PDG 解码

新增 `HH 02 46` 文本容器中的 `0x1A` 编码。此分支按头字段计算文本流的变换位置，校验 zlib 数据并还原原始 PDF。阅读器沿用已有的 PDF 分段页序、正文页码定位和矢量绘制。图像型同编号 PDG 仍使用其自身的算法。其余文本变体须逐一验证后再加入。

生成夹具覆盖文本分支的逐字节还原、16 位字段、变换位置重叠、字节表末位、校验损坏与截断，以及多个分段的页序和目录映射。图像型和无变换文本型的现有夹具一并验证。

## 2. 样书与界面

实书 8 个分段的输出与独立参照逐字节一致。按原页码展开为连续的 285 页，285 页均成功渲染，279 页可从 PDF 提取非空文字层。阅读器通过双页、连续阅读、翻页、缩放和旋转检查。样书第 6 页在 2、4、8 倍绘制的像素与相同尺寸的 PDFKit 参考绘制一致。

快速预览使用同一解码器。通过生成的三页彩色文本 PDG 验证原生预览控制器的翻页、末页定位与缩放。该验证直接运行控制器。原书及参考应用只在本机读取，原书 SHA-256 和修改日期核对一致。源码包和安装包仅含程序与生成测试，不含原书内容。

## 3. 回归范围

354 项功能检查通过，另有 26 项原生阅读与预览界面检查通过。

多语言 OCR 套件的简体中文夹具在本机将“丛书名”误识为“从书名”。在本机已安装的 0.21.0 中复现了相同识别结果。解码与阅读验证独立记录。
