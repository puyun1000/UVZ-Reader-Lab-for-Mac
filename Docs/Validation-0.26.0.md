# 0.26.0 验证记录

## 1. 旧目录与 PDF 书签

编辑并保存四份 PDG 教程档案副本，分别保留 93、71、138 和 650 条目录。其中 945 条未附目标页的原记录保留了页面类型和页号。修改其他标题时未丢失这些记录。旧目录按双字符 36 进制层级路径读取和写入。合成测试确认新录入的无效页号及无法解析的旧目录会阻止覆盖。

在一份 267 页的 PDF 副本中只改一个书签标题。回读确认 51 个原目标的坐标、缩放和物理页均保留，分段页标签一致，原 PDF 字节保留在增量修订之前。另用合成 PDF 检查横向适配目标、外部 URI 动作及原有页标签。同页多个原目录身份无法从文本唯一判断时，会提示撤销改动后在树形模式分别编辑。

教程样本、图像和原文件不随发行包提供。本机使用临时副本写入，测试前后比对只读样本的文件哈希和修改时间。

## 2. 原生原页预览

目录编辑使用原生工具栏。预览与草稿同窗，草稿支持文本和树形两种方式。预览可折叠、翻页、输入物理页号和缩放。选择含有效目标的目录项后可查看该目标页。框选识别使用当前预览页面，结果仍需进入草稿并确认保存。本轮的联动到页，原图中的 OCR 词行尚无法与草稿逐条反选。

## 3. 回归范围

421 项功能检查、76 项原生界面检查和 11 项 Quick Look 预览控制器检查通过。原生界面包含编辑与批量保存流程 21 项、转换与阅读 31 项、批量预览及书签流程 24 项。在线书签采用模拟返回数据。多语言 OCR 测试中，简体夹具的「丛书名」被识别成「从书名」，与 0.25.0 相同，未计入通过项。

Apple 芯片 Mac，最低 macOS 14。安装包为临时签名，未经 Apple 公证。组件架构、镜像签名和发行校验信息见随包验证摘要。
