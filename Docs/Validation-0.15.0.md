# 0.15.0 发布验证

日期：2026-10-25。版本0.15.0，构建16。

## 构建与运行环境

- 原生Swift/AppKit，Apple Silicon arm64，声明并核验最低macOS14.0。
- 本次实际测试系统macOS27.2；未覆盖所有支持系统版本实机测试。
- 主程序、两个DjVu工具及两个Quick Look扩展均核验架构及Mach-O最低系统版本。
- 干净解压、安装镜像及复制后的应用签名校验通过；为ad-hoc临时签名，未经Apple公证。

## 功能与交互检查

- 288项功能检查，包括归档解码、目录页号、原生信息保存、OCR及命名、PDF转换、在线接口离线契约、文字转换和默认配色持久化。
- 76项原生界面检查，包括上下转换布局、长目标名、取消重启、直接点击适合宽度／高度／整页、默认配色、输入框中文菜单、Unicode选区转换与撤销、阅读页面常用右键操作、目录和信息编辑及Dock图标。
- 11项多页预览控制器检查；系统日志确认实际加载0.15.0预览扩展。系统远程预览视图内的交互由同一原生控制器检查，未自动点击远程视图。
- 实书190个物理页面全部输出，190张JPEG压缩字节逐张保留，28条PDF目录目的页核对正确；来源内容及日期未改动。书目页数保留其含义，不被物理页数覆盖。
- 本轮没有发起在线书目查询或消耗第三方配额；接口和草稿导入沿用离线样本，之前实测情况见OnlineReferences.md。
- 发布前扫描拟提交源码和既有Git历史；不上传测试图书、扫描页、私人截图、调试缓存或凭据。

## 发布边界

转换仍不支持RAR、CBZ、加密归档、选定页导出或压缩参数；超过8位的栅格页明确拒绝，不静默降低精度。DjVu的PPM转换路径使用回退DPI确定纸张尺寸，图像像素保持原尺寸。文字转换仅处理选择范围；只读内容转换后复制。识别与书目信息推荐仍需核对。

源代码、打包说明、第三方源码和许可证与本次标签一起发布；对应DMG、源码包、校验表及本摘要作为GitHub Release附件提供。
