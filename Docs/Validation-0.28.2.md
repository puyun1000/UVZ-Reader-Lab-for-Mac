# 0.28.2 验证记录

在实书的临时副本中载入 PdgCntEditor 写入的压缩目录，编辑标题并回读。40 条书签的层级与跳转目标一致，382 个页面及图书信息的压缩数据完整保留。原书哈希、大小及时间戳已核对。

使用生成的归档验证缺少 Adler-32 尾部但压缩内容完整的目录可编辑和保存。压缩数据截断、校验码错误、只剩部分校验尾部及有多余字节的样本仍被拒绝覆盖。原生界面也验证有正文断号提示时可正常保存可读目录。

分别保存图书信息和目录，核对 ZIP 本地头、中央目录和解包文件的时间。新写入的 DAT 使用保存时间，其余条目日期保持原值。勾选“保持文件日期”时，外层文件保留原创建及修改日期。

通过 448 项功能检查、98 项原生界面检查和 13 项 Quick Look 控制器检查。既有简体 OCR 样例将“丛书名”识别为“从书名”，未计入通过数。

适用于 Apple 芯片 Mac、macOS 14 或更新版本。发行包采用临时签名，未经 Apple 公证。
