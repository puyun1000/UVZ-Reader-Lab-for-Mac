# 0.23.0 验证记录

## 1. 格式兼容

新增生成夹具覆盖四种 PDZ 容器组合、证书到期和 CRC 损坏、EPUB 2 NCX 与 EPUB 3 导航、十二个文本 PDG 变换分支、三个 A 系列变体、预处理、JPEG 矩形覆盖层、明文 DjVu 与非零原点 PDF 裁切，共 26 项。

PDZ 保留证书、有效期、类型、边界与 CRC 检查。使用构造的有效证书测试，尚缺真实 PDZ 图书验证。PDZ 当前提供只读阅读、预览与 PDF 转换。EPUB 提供基本章节阅读，目录解析在三本本地图书中通过，实际 WebKit 正文加载、切换章节和保留窗口关闭图书的界面检查通过。复杂固定版式、交互内容和加密 EPUB 未作完整兼容验证。

## 2. PDF 原图核对

两本用户提供的印前 PDF 均存在 MediaBox 与 CropBox 不一致的情况。核对窗口改用 CropBox 与原生 PDFView，支持矢量放大和适合宽度。OCR 位图独立按成书区域生成，长边以 2400 像素为目标，最高 4000 像素。

两本实书分别生成 1494×2400、1698×2400 的测试图像，与独立 Poppler 裁切渲染相比，平均像素差分别为 4.034、2.199，范围为 0—255。界面检查验证实际 CropBox、矢量缩放及宽度适配。测试使用临时副本，原件 SHA-256、修改时间与副本内容核验一致。

## 3. 阅读与在线目录

护眼色、亮度、彩色页自动对比度保护、灰度扫描自动对比度以及旧版阅读状态迁移通过生成夹具检查。PDF 在无显示调整时继续使用矢量绘制，启用调整时按当前窗口与屏幕像素渲染。显示调整保持独立于原文件和 OCR 输入。

在线目录通过离线响应注入验证当前 SS 号、切书更新、来源不匹配限制及直接添加目录草稿。未将离线检查作为服务器在线可用性的证明。

## 4. 回归结果与边界

385 项功能检查通过。另有 98 项原生窗口检查通过，包括编辑与保存 14 项、转换工作台 31 项、阅读与在线目录及原图窗口 9 项、EPUB 4 项、两本实书核对各 9 项，以及 PDZ、UVZ 预览控制器各 11 项。预览检查直接运行扩展控制器，未验证 Finder 的扩展选择与调度。

多语言 OCR 套件在本机将简体夹具的“丛书名”识别为“从书名”，后续断言因此停止。同一夹具在已安装的 0.22.0 中复现相同结果。本版保留此问题记录，未计入通过项目。

发布包适用于 Apple 芯片 Mac、macOS 14 及以上。应用使用临时签名，未经 Apple 公证。安装镜像、干净解压、七个 Mach-O 的架构和最低系统版本、公开发行附件与源码标签由发布步骤另外核验，结果记录于发行验证 JSON。
