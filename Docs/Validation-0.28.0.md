# 0.28.0 验证记录

使用生成的 PDF 测试有可见文字与细线的排版页、接近 300 dpi 的整页图像、带隐藏文字的扫描页、混合页面和空白页。PDF 类型建议基于正文样页。文件名标记用于整理，样页判定仍需要核对特殊页面。

使用生成的版权页文字核对朝代国名、并列姓名、不同著作方式、版本说明、数字版次、正文页数及定价。新增字段通过 PDF 文件保存与回读核验。批量窗口检查上方书单、下方同屏预览与图书信息、缩窄窗口和切换图书后的阅读位置。

通过 436 项功能检查、89 项原生界面检查和 11 项 Quick Look 控制器检查。已知简体 OCR 样例仍将“丛书名”识别为“从书名”，未计入通过数。

发行包支持 Apple 芯片 Mac、macOS 14 或更新版本。采用临时签名，未经 Apple 公证。
