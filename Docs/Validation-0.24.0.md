# 0.24.0 验证记录

## 1. 批量核对与工具栏

在 32 页 PDF 样本中，从批量命名书单跳到第 16 页，验证首尾识别候选以外的正文可独立浏览。切换书单行后，同一预览区显示另一本 UVZ 的第一页。PDF 用矢量绘制，UVZ 图像按原始页面读取。

通过实际工具栏按钮打开「目录与封面」和「调整页面」。在线按钮紧邻图书信息，测试只打开查询窗口。页面调整界面完成了双栏预览、指定范围和同格式保存，校验副本并比较了原件字节。

## 2. 三种格式的保存

- PDF：带偏移 CropBox 和原生旋转的页面完成四边裁剪和旋转，保留矢量、文字、链接及目录。对不连续范围应用色调调整，只栅格化所选页。
- UVZ／ZIP：保存旋转裁剪后的扫描页，校验页面尺寸、可见方向与 DPI。修改多页文本 PDG 的单个逻辑页后，仍可按原页序跳转。未修改的归档成员、元数据和目录通过回读。
- DjVu：验证原生旋转、单页重编码及不连续页裁剪。裁剪或色调变化有损重编码所选页，移除所选页的隐藏文字和页面注释。目录和图书信息回读一致，未选页的渲染像素一致。
- 事务：拒绝越界页码、非法裁剪、已有目标文件及同名信息目录。只有在页数、页序、目录、图书信息和来源指纹均核验后才提交副本。

另用三本实书另存旋转和裁剪副本，覆盖 282 页矢量 PDF、285 页文本 PDG UVZ 和 190 页扫描 UVZ。实书原件的 SHA-256 与修改时间前后相同。

## 3. 回归范围

393 项功能检查通过。原生交互另外通过 55 项，包含本轮新增的 10 项、编辑和批量保存流程 14 项、转换工作台 31 项。Quick Look 原生预览控制器通过 11 项，验证翻页、页码输入、缩放及窗口适配。该测试直接运行预览控制器。

多语言 OCR 套件在简体夹具将「丛书名」读成「从书名」。在本机安装的 0.23.0 上复现相同结果。该失败用例未计入通过项。

6xH 文本 PDG 提示需要原授权数据。此次变更为格式诊断。发布应用为 arm64，最低 macOS 14，临时签名且未经 Apple 公证。发行验证 JSON 包含安装镜像、随包组件与源码提交的核验记录。
