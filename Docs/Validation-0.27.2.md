# 0.27.2 验证记录

## 1. PDF 同页书签

用一份 336 页的 PDF 副本复现 0.27.1 的两处报错，分别将一个页码书签替换为同页父项和子项。0.27.2 一次保存两处，独立回读确认四个新书签的层级、页码及整页目标，其他 322 条书签的标题、层级和原目标均未变。样本只作本地验证，原文件只读。

原生窗口测试确认文本模式可直接保存同页父子项。生成样本同时验证了同名、同页子项不会继承父项的坐标，已有同页书签成批改名仍保留原坐标、缩放和链接。

## 2. 回归与发行

通过 428 项功能检查、86 项原生界面检查和 11 项 Quick Look 控制器检查。已知简体 OCR 夹具仍将“丛书名”识别为“从书名”，未计入通过数。在线查询使用模拟结果。

发行包支持 Apple 芯片 Mac、macOS 14 或更新版本。采用临时签名，未经 Apple 公证。
