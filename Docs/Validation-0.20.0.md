# 0.20.0验证摘要

日期：2026-11-02。Apple芯片、macOS14以上；本机macOS27.2。

1. 原因：旧阅读路径把PDF固定绘制成每点最多2像素、长边最多4000像素的图像，随后继续拉伸。新阅读页直接调用PDFKit向当前窗口设备上下文绘制；分析图像仍供OCR、缩略分析及独立图像导出使用。扫描PDF不会因此增加原图细节。
2. 功能：370项生成夹具检查通过。新增独立PDF、单个文本PDG、UVZ内嵌PDF的源页面取得与2／4／8倍绘制对照；实际阅读窗口检查矢量视图在旋转、反色、适合宽度后持续安装；原PDF字节不变。矢量视图保留文档生命周期，缓存文档与分析文档分别使用，页面移出附近区域后仍按原机制回收视图。
3. 实书只读：使用用户提供的401页印前PDF，正文样页含矢量文字。旧分析图为1094×1508，新8倍测试为4377×6032；三种输出尺度与同尺寸的原生PDFKit绘制平均像素差均为0。实际阅读窗口4项检查通过，原始SHA-256及修改日期不变；放大局部已目视核对。书籍、样张和私人路径不分发。
4. 界面：既有31项阅读／转换和14项目录／工作流检查照常运行，结果见发行验证JSON。本轮不将访达系统预览回调计为已验证；预览扩展及独立图像导出仍采用各自的位图路径。
5. 发行：源码与两扩展同步0.20.0/build24，核验7个arm64 Mach-O的macOS14最低版本、签名、DMG及镜像复制；源码及分发内容扫描后发布，线上附件摘要核验后清理本地重复产物。临时签名，未经Apple公证。

复现：build.sh后执行scripts/verify-functionality.py；新增Tests/test_pdf_vector.py。--pdf-vector-test仅为离线诊断输出对照图，不改输入文件；实际阅读验证使用--pdf-reader-display-test。生成及实书中间图不属于发行文件。
