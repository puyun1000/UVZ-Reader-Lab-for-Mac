# 0.25.0 验证记录

## 1. 批量规范命名

用生成的 32 页 PDF 和 6 页 UVZ 样本测试。书单贯穿工作区高度，默认尺寸和 1040 × 650 窗口中均占较大宽度。可在固定预览中跳至第 16 页、切换图书和恢复页码。PDF 预览使用矢量页，UVZ 预览读取原始页面图像。

点击书单或自动分析完成时保持未勾选。修改书目信息及确认人工核对时自动勾选，单改文件名不改变核对状态。手工文件名在调整书目信息时保留。从文件名单元格拖框实测可同时勾选多本，表头可取消全部。

## 2. 补书签

在阅读工具栏和批量命名中打开仅书签的查询窗口。批量窗口验证选中书目的 SS 号、测试查询数据进入目录草稿、确认之前文件保持不变、保存后回读书签及批量草稿的文件指纹。原有书目草稿和勾选仍可用于改名。在线流程使用测试返回数据，未访问查询服务。

## 3. 发行回归

393 项功能检查和 69 项原生界面检查通过。其中批量预览、补书签和页面调整 24 项，原有编辑及批量保存流程 14 项，转换工作台及阅读功能 31 项。Quick Look 预览控制器通过 11 项，包含翻页、跳页、缩放和调整窗口。多语言 OCR 套件的一项简体夹具将「丛书名」认成「从书名」，在本机已安装的 0.24.0 上复现。该失败未计入通过项。
