# 0.21.0 验证记录

## 1. 批量分析和编辑

旧版对每本 PDF 先构建阅读用文档和目录，再逐张渲染首尾候选页并进行 OCR。编辑字段时，整张书单重载，状态列与详情重复计算相同的来源判定。

本版在工作队列上使用 PDF 批量读取路径，仅访问内嵌书目与候选页。首尾各十页去重，内嵌文字足以提取明确著录或识别普通文本页时复用文字层，缺少可靠文字时进行 OCR。普通候选页保留原文核对入口，封面和前段书名页的版面推断仍用 OCR。可显式改为逐页 OCR。分析前后继续核验图书内容与旁存信息的完整摘要，应用改名前仍校验摘要和名称冲突。

来源判定随分析结果缓存。书目输入只刷新受影响的表格单元格与字段，后台分析完成时仅更新对应行。逐字测试通过原生文字编辑器在相同的 48 行建议中连续输入 40 个汉字，每次计入更改通知与窗口布局。旧版中位耗时 671.2 毫秒、第 95 百分位 680.2 毫秒。新版分别为 2.3 和 2.5 毫秒，两组均未丢失焦点。该测试使用五本图书的分析结果填充书单，用于独立隔离界面处理。

混合 PDF 夹具包含后段文字层版权页和图像版权页，验证两条路径可提取 ISBN，并保留逐页 OCR 和短书候选页去重行为。

## 2. 阅读识字

可见页的手动识别使用原有 VisionKit 文字选取。自动识字是独立的持久偏好。关闭自动识字后，已识别的文字仍可选取。阅读窗口的开关与批量命名、版权页及框选识别分别控制。

## 3. 回归与验证范围

371 项功能检查通过。原生窗口验证包括阅读器 11 项、批量命名 7 项、编辑与保存流程 14 项、转换工作台 31 项，共 63 项。阅读识字测试在关闭自动识字时仍成功识别并选取文字。

整批实书验证限定文件夹顶层的 PDF，以临时副本运行。测试期间不执行改名或写入书目，分发包仅保留汇总指标。扫描图书的文字识别速度仍受页面数量、版式与扫描质量影响，著录内容需人工核对。
