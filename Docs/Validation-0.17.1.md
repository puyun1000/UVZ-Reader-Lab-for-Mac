# 0.17.1 验证摘要

日期：2026-10-27。目标为Apple芯片、macOS14或更高；实际运行环境为本机macOS27.2。

1. **功能**：330项生成夹具检查通过。新增PDF、DjVu原生目录的分组、多级、中文长标题、清空目录、备份、旧DAT迁入、未知用户文件保留及失败事务检查。PDF覆盖压缩对象、交叉引用流、PNG预测、混合修订链、混合引用及连续三次保存，独立pypdf核对目标页；每次修订保留之前的完整文件字节。非法输入不替换原文件。
2. **实书副本**：415页PDF添加目录后，逐页解码图像及文字内容核对一致；原书SHA-256、修改日期和创建日期不变。仅使用本机临时副本，书籍与页面不分发。生成PDF同时核对原始信息字典中的名称、日期及制作工具等字段类型和值，避免系统组件将PDF名称转换成文字。
3. **界面**：31项既有原生交互、11项新增工作流检查通过；新增覆盖目录分隔线调整和隐藏恢复、长行不折页码及横向滚动、批量保存全部核对字段并保留目录。另对两种字号、三种栏高共6种输入状态渲染测量，输入前后字形上下边界完全一致。
4. **预览**：11项原生预览控制器检查通过，包括实际逐页解码、跳转、缩放及窗口适配。本轮未将系统访达扩展回调计为实测通过，也未替换已安装应用。
5. **发布**：源码、应用与两个扩展为0.17.1/build20；分发包核对干净解压签名、DMG签名、7个Mach-O的arm64架构及macOS14最低版本，发行验证JSON与SHA256SUMS在安装包旁提供。发布前扫描源码和分发内容，发布后核对线上附件摘要与标签提交。
6. **边界**：PDF目录仅改写结构及信息字典，页面数据保留；加密或不能安全解析的文件拒绝保存。PDF、DjVu信息及目录写入文档，ZIP／UVZ写入包内DAT；PDG文件夹写DAT，单个PDG和TIFF仍使用既有伴随信息方式。旧版V1、28H解码仍主要经生成样本验证。应用临时签名，未经Apple开发者签名或公证。

复现：先运行build.sh；安装requirements-test.txt中的依赖后运行python3 scripts/verify-functionality.py。Tests/test_workflow_ui.py运行新增原生工作流；Tests/FieldAlignmentTests.swift与Source/NativeEditing.swift可单独编译，输出字形测量JSON及临时PNG。QuickLook/Tests/PreviewControllerTests.swift用于原生控制器检查。生成样本与中间图像不属于发行文件。
