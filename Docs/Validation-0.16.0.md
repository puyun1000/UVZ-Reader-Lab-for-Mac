# 0.16.0 验证摘要

日期：2026-10-26。目标为Apple芯片、macOS14或更高；实际运行环境为本机macOS27.2。

1. **PDF图书信息**：312项功能检查通过。其中无信息字典的生成PDF覆盖两种文件名、仅保存和保存并改名、重复修改、经典交叉引用、交叉引用流及追加修订链。独立pypdf回读书名、ISBN等原生字段；信息修复结果保留原始PDF完整字节作为前缀。
2. **真实PDF复核**：对用户提供的415页PDF仅使用临时副本，分别以含ISBN/尾部标识符和短文件名进行保存、改名及再次修改。书目字段、页数、完整目录及目标页、逐页文字和注释数量、页面尺寸和旋转均核对；抽查4页渲染像素一致。源文件SHA-256及原始日期不变。未产生新的uvzmeta文件夹，事务临时文件清理完成。原始PDF缺少Info字典，与文件名本身无关。
3. **PDG兼容扩展**：15项生成夹具检查覆盖V1、10H、28H、AAH/ABH/ACH、公共预处理、JPEG2000及异常输入；在压缩包内读取并转PDF通过。另对32个上游PDG样本逐页实际渲染通过，JPEG/DjVu解码负载与固定上游算法比对一致。样本图像及Windows DLL均不分发。
4. **界面**：31项原生交互检查通过，包括单行栏框的显示及编辑纵向居中、保留多行布局、原有转换工作台/阅读操作、中文菜单及文字转换。使用原生窗口离屏渲染复核。
5. **预览**：11项原生预览控制器检查通过；在与扩展相同的应用限制下，独立DjVu工具成功解码。系统有多个历史预览扩展，本轮未取得可确认是0.16.0的访达系统预览回调，因此不将其计为系统实测通过。临时测试应用已移除，原应用和已安装的阅读器保留。
6. **发布包**：干净解压和DMG内代码签名、7个Mach-O的arm64架构和macOS14最低版本、应用和两个扩展的0.16.0/build18版本一致性均核验。发布前扫描源码及分发包，上传后核对附件哈希。详细结果见发行验证JSON及SHA256SUMS。
7. **已知边界**：V1及28H主要使用生成样本验证；复杂TIFF/JPEG2000受系统支持范围约束，不承诺覆盖所有历史PDG。加密PDF不改写信息。本版使用临时签名，未通过Apple开发者签名或公证。

复现常规功能测试：安装requirements-test.txt所列测试依赖，运行build.sh，再执行python3 scripts/verify-functionality.py。真实PDF可用Tests/test_missing_pdf_information.py --source指定本地文件，仍只改写临时副本。
