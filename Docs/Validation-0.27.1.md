# 0.27.1 验证记录

## 1. PDF 目录

在 0.27.0 上用生成的 PDF 复现报错：同一物理页的两个书签分别指向不同的坐标和显示样式，文本模式同时改名会被拦下。0.27.1 通过原生目录窗口的“全部替换”、文本与树形切换、文本保存及 PDF 独立回读。

- 同页改名分别保留 XYZ 坐标及缩放、FitV 和 FitH 跳转参数；无页码的两个链接书签也分别保留各自的地址。
- 移动未改名的书签，仍指向原落点；树形删除条目后在同页新建条目，新条目使用整页目标。
- 同页改名和增删无法逐一对应时，报告对应物理页，原文件字节未改动。

## 2. 构建与回归

在干净构建中发现 macOS 的 make 可能重用通用 DjVu 工具的旧链接结果，导致页面调整后的另存失败。更新构建脚本强制重新链接，使用生成样本验证指定页能够替换，未调整的页面和原有目录保持不变。

通过 427 项功能检查、85 项原生界面检查和 11 项 Quick Look 控制器检查。一项简体 OCR 夹具仍将“丛书名”识别为“从书名”，与此前相同，未计入通过数。在线查询使用模拟返回，本轮测试仅写入临时样本。

发行包支持 Apple 芯片 Mac、macOS 14 或更新版本。采用临时签名，未经 Apple 公证。
