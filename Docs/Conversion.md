# 转换实现与验证范围

本版将转换放在独立原生窗口，和阅读、目录编辑分别组织。窗口采用上下卡片：任务及完整性预览在上，输出设置在下，完整目标名可换行；小窗口可上下滚动，不另开选项面板。窗口以单队列逐本处理，后台读取和转换，主线程更新状态。导入阶段不保留一批已展开的图书对象；工作台的任务仅保存来源、元数据、名称和状态。

默认完整保留来源名称，显式切换时才使用共享格式库或仅书名。单独修改的目标名不因模板切换而丢失，重新生成才能恢复自动跟随。来源BookInfo缺少SS号时沿用现有单书窗口的文件名回退规则。

## PDF路径

- JPEG：读取图像头的颜色、尺寸、方向、DPI与ICC，符合支持范围时直接嵌入原始JPEG字节，不重新压缩。灰度与RGB分别声明；其他颜色模型转为无损RGB。
- 其他图像：解码成原尺寸灰度或RGB，以Flate无损输出；检测到纯黑白时使用一位像素。透明区域铺白。超过8位的栅格页明确拒绝，避免静默降低精度。
- 多页TIFF：每帧单独读取尺寸与图像属性，不能重复首页。
- DjVu：调用随应用提供的DjVuLibre，以原始尺寸和彩色PPM解码。该PPM路径不携带来源DPI，输出纸张尺寸采用工作台的回退DPI；像素不缩小。
- 文本PDG：使用Core Graphics绘制嵌入PDF页，保留文字及矢量，处理旋转与非零页面原点；混合书中的图像也走此上下文路径，不保证JPEG字节直通。
- 原生PDF：从副本处理信息；没有信息改写或目录覆盖时保留原始字节。PDFKit信息及目录写入采用独立临时文件，并回读校验。PDFKit的可变页写入会丢弃自定义信息，因此先使目录持久化，再重新打开写入完整信息。

纯图像PDF按页写入文件句柄，只保留交叉引用位置和页对象编号，不把整个输出PDF攒在内存。PDFKit和Core Graphics处理原生／混合PDF时会使用系统自己的缓存，因此不承诺所有格式都具有相同内存表现。

## 页号、信息与输出提交

目录使用BookArchive解析后的实际物理页索引，输出时通过来源索引到结果索引重新映射。跳过页不生成虚构占位页；没有有效目的页的条目保留标题，避免跳错。分组、层级、前后节点关系和书名等使用Unicode PDF字符串。

书目中的“页数”与实际PDF页数不同，原样保留其书目含义。扩展字段写入PDF内部的UVZReaderLabMetadata，标准字段同时映射到文档属性，不产生BookInfo旁存。

开始前检查目标目录、非法名称、同源PDF和大小写／Unicode规范化重名，最终用RENAME_EXCL提交，防止检查后出现的新文件被覆盖。来源指纹前后比对，转换不写来源。默认坏页停止；显式跳过时输出.partial.pdf，日志列出缺页及目录情况。取消在处理阶段间和逐页检查，当前临时结果清理，已完成图书保留。

## 可复现验证

构建：`./build.sh`。开发测试需要Python、Pillow、pypdf、reportlab及pdftoppm；应用运行无需这些依赖。

- `python3 Tests/test_conversion.py`：压缩字节、无损图像、多页TIFF、文本PDG、原生PDF链接和目录、EXIF八种方向、旋转原点、元数据、取消、坏页、防覆盖和DjVu。
- `python3 Tests/test_conversion_ui.py /绝对路径/conversion.png`：临时生成两本测试书，检查原生工作台、命名保护、窄窗口、取消恢复、输出以及在线参考草稿。不会发起网络查询。
- 应用可执行文件的`--online-model-tests`：离线检查请求字段、SS号、返回身份、地址约束、配额及DAT转换。

发布实测、运行环境与局限记录在Verification.json。RAR、CBZ、加密归档、选定页导出及压缩参数尚未加入。在线参考服务不是转换依赖，服务器内部实现未知，其稳定性和图书覆盖范围不能由本项目保证。
