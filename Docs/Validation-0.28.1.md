# 0.28.1 验证记录

单本窗口验证原页与分组图书信息同窗显示、并排字段宽度、跨栏命名区及从原页采用版次。批量窗口验证全宽书单、窄窗口布局、字段宽度、矢量预览、换书保留页码、人工核对后勾选及信息保存。界面测试使用生成的临时图书。

使用自定义模板及批量提议分别验证第 1 版的常见写法、旧出版日期括注和第 2 版。可保存并重读原有数字版次，自动生成的文件名省略第 1 版。

通过 444 项功能检查、95 项原生界面检查和 13 项 Quick Look 控制器检查。已知简体 OCR 样例仍将“丛书名”识别为“从书名”，未计入通过数。

发行包支持 Apple 芯片 Mac、macOS 14 或更新版本。采用临时签名，未经 Apple 公证。
